# Easy酒馆Pro v1.2 正式版至 v1.39 早鸟测试版功能更新传递稿

> 更新时间：2026-08-06  
> 当前版本：v1.39 早鸟测试版  
> 后续计划：v1.40 作为最终稳定版，原则上只进行 Debug、兼容性与文档维护。  
> 本文仅记录已经落地的功能。TTS、超大同步包预检等仅完成评估但尚未落地的项目，不计入正式功能。

## 一、对话系统

- 角色 A、角色 B 可分别绑定独立文字模型，允许按角色重要程度和使用频率控制成本。
- 移除模型设置页中容易产生优先级冲突的对话模型勾选，只保留蒸馏模型等专项绑定。
- 新增“同时告知”功能：同一条玩家消息按 A 后 B 的顺序分别请求，两名角色读取相同的发送前对话快照，避免 A 的回复提前影响 B。
- 新增流式输出开关，可切换“流式输出中 / 已关闭流式”。关闭流式有助于提升部分模型和 MVU 协议的完整性。
- 新增当前对话专属的 `{{user}}` 名称与一句话描述，兼容传统酒馆角色卡中的玩家宏。
- 角色卡可配置第一句预设对话。空白对话首次加载时自动生成 assistant 气泡，严格按照角色 A、角色 B 的顺序加载，并防止重复生成。
- 长对话切换后恢复原滚动位置，不再自动跳回顶部或强制滚到底部。
- 聊天滚动条增加顶部、中间百分比节点和底部快捷定位，节点改为半透明竖向胶囊。
- 重试、删除和分支操作强化时间线清理，避免残留状态书、蒸馏结晶或孤立附属节点。
- 修复分支对话共享输入历史的问题，分支创建后保持独立消息时间线。

## 二、长对话性能与对话管理

- 消息存储升级为 v3 分片索引：每条消息独立存储，每个对话维护轻量时间线索引。
- 聊天界面默认分页读取最近消息，向上滚动时再加载旧消息。
- 状态书计数、蒸馏规划和上下文组装优先读取索引与必要窗口，不再反复扫描完整历史。
- 分页游标采用时间戳与消息 ID 组合，避免同毫秒消息被遗漏。
- 新增对话文件夹：支持自定义名称、折叠、管理成员和删除。
- 删除文件夹需要确认，且只删除文件夹结构，内部对话会返回主列表。
- 默认教学对话自动归入“预制教学对话”文件夹。
- 重构创建对话角色选择界面，解决双层下拉、弹窗吸顶和移动端无法选择底部角色的问题。

## 三、记忆蒸馏系统

- 自动蒸馏与手动蒸馏统一使用完整对话轮次规划器。
- 一轮由一条 user 消息及其后续角色回复组成，不再拆散 user/assistant。
- 不足触发阈值时不会调用模型，修复手动蒸馏只处理单轮甚至单条消息的问题。
- 自动与手动蒸馏加入互斥锁，避免同一批消息被重复蒸馏。
- 蒸馏提交改为事务式流程：来源归档、索引更新和结晶写入在同一锁中完成，失败后自动回滚。
- 新结晶支持累计记忆，只向上下文注入最新累计结晶，减少重复 Token 消耗。
- 记忆回廊新增编辑按钮，可直接修改已生成的蒸馏记忆。
- “最大蒸馏节点数”更名为“最大注入记忆数”，明确其实际作用。
- 蒸馏输出兼容 `content`、`text`、`reasoning_content` 等返回结构。

## 四、世界书与缓存世界书

- 每张角色卡可绑定两本世界书：
  - A 世界书：玩家手动维护的长期世界书。
  - 缓存世界书：可选的 AI 自动维护世界书。
- 缓存世界书最多保存 10 条词条，避免状态维护 AI 注意力过载。
- 状态书/书记 AI 可扫描负责轮次中的重要人物、道具和世界观变化，通过 JSON 操作新增、更新或删除缓存词条。
- 缓存词条新增“升华”按钮，可手动迁移到角色的 A 世界书。
- 缓存世界书 JSON 接口加入严格校验，只接受合法操作、关键词、正文和有限优先级。
- 已存在于 A 世界书的关键词不会重复写入缓存世界书。
- 原世界书条目默认折叠，减少长列表造成的视觉负担。
- 废除世界书插入冷却逻辑，改为“扫描深度 + 最大插入条目”：
  - 扫描深度决定向前读取多少条历史 user 对话及其间的角色回复和记忆。
  - 最大插入条目决定一次最多向模型提交多少条命中设定。
- 世界书正文只在最终请求阶段组装，不写入历史消息。
- Debug 导出会标明命中的世界书与预估 Token，方便玩家检查消耗来源。
- 状态书维护缓存世界书的功能提示词已加入高级提示词设置，可自由编辑。

## 五、角色卡与酒馆兼容

- Easy 角色卡组装器新增第一句预设对话字段。
- 导入 Character Card V2 时兼容：
  - `first_mes`
  - `alternate_greetings`
  - `creator_notes`
  - `system_prompt`
  - `post_history_instructions`
  - `tags`
  - `creator`
  - `character_version`
  - `character_book`
- 支持从 PNG 与 JSON 导入酒馆角色卡。
- 角色专属 `character_book` 会转换为 Easy酒馆Pro 世界书。
- 导入 MVU 卡时默认开启“创建对话时自动启用 MVU”，确保第一句加载前变量系统已经工作。
- 修复角色卡导入或 Easy 组装保存后偶发未创建角色的问题。
- 导入过程加入数据验证、编码检测与错误回调，兼容部分 GBK、Latin-1 和异常中文文件。
- 新增 GitHub 公共角色卡商店：
  - 支持绑定公开仓库地址。
  - 保留仓库文件夹层级。
  - 支持列表与缩略图模式。
  - 可直接下载并导入 PNG/JSON。
  - 仓库内容即时加载，不缓存远端角色卡。
  - 明确提示文件识别属于扩展名初筛，无法保证所有 PNG/JSON 都是有效角色卡。
- 不支持私人 GitHub 仓库，降低 Token 权限和配置复杂度。

## 六、MVU 兼容引擎

- 新增 SillyTavern MVU 变量状态兼容系统。
- 支持从角色绑定世界书识别 `[InitVar]`、`[mvu_update]`、`[mvu_plot]` 等条目。
- InitVar 兼容 JSON、JSON5、YAML 及常见的说明文字包裹格式。
- 支持 `<UpdateVariable>`、JSON Patch、脚本式 `_.set()` 等常见更新协议。
- 变量状态只允许在合法路径上更新，旧值不匹配或规则校验失败时拒绝写入。
- 每 8 个有效回复保存一次完整快照，分支后可按时间线重新回放状态。
- MVU 气泡附着在角色回复下方、状态书气泡上方，并支持折叠。
- MVU 面板展示核心字段、更新数量、初始化诊断和规则错误。
- 规则校验失败时提供醒目提示，建议更换模型或调整 MVU 提示词。
- DeepSeek 等模型未输出更新块时，可使用独立 MVU 维护请求进行兜底更新。
- 调试模式可导出模型完整原始响应，便于排查不同模型的协议差异。
- MVU 提示词经过压缩和协议强化，减少无关说明对模型输出格式的干扰。
- 明确提示不推荐同时开启 MVU 与模块化 Gal/RPG，避免重复记录和额外消耗。
- 不执行 Tavern Helper 脚本或动态 Schema，仅兼容静态变量、规则与更新协议。

## 七、模块化 Gal/RPG 引擎

- 原状态书与 Galgame 引擎重组为“模块化 Gal/RPG 引擎”。
- 独立书记 AI 根据玩家启用的模块拼接提示词，并输出结构化 JSON。
- 支持以下模块：
  - 自由文本
  - 世界横幅：日期、地点、组织与势力
  - 角色面板一、角色面板二
  - 生命、心情、Buff、自定义货币
  - 背包与物品栏
  - 角色关系
  - 事件栏
  - 配角栏
- 两个角色面板均可独立启用并填写角色名，书记 AI 会按角色名维护对应 JSON。
- 新增组装预览车间，直接展示最终气泡中的完整模块效果。
- 模块字段提示词可单独编辑，玩家可控制每个字段的更新判断方式。
- 状态气泡继续吸附在角色回复下方，并允许编辑；非法字段不会覆盖原数据。
- 旧状态书和 Galgame JSON 会迁移到兼容字段中，升级后仍可查看。
- 身体状态模块细分头部、躯干、大臂、小臂、手、大腿、小腿和脚。
- 基础身体状态支持健康、轻伤、重伤与缺失等颜色显示。
- 新增默认关闭的身体特殊状态系统：
  - 可分别绑定角色 A 或角色 B。
  - 可选择具体身体部位。
  - 同一部位支持多个特殊状态。
  - 特殊状态使用粉色描边叠加，保留底层基础伤势颜色。
  - 点击身体部位可查看玩家预设的特殊状态文本。
- 模块 UI 升级为 RPG HUD 风格，强化世界横幅、身体面板、属性子板、背包、任务日志与配角徽章。
- 加入作者问答彩蛋，解锁后角色 A 身体模型会叠加特殊 SVG 服装，不影响底层状态显示。

## 八、表情包系统

- 支持最多 2 组本地表情包，每组最多 8 张。
- 上传时要求填写明确的情绪或用途标签。
- 静态图片自动压缩，GIF 最大支持 1.8 MiB。
- 表情包以 Blob 保存于 IndexedDB，不直接塞入普通业务状态。
- 对话中可分别为角色 A、角色 B 绑定不同表情包组。
- AI 通过 `<EJP_STICKER>` 工具协议调用表情包，并按调用位置插入气泡。
- 修复第二条及后续气泡表情包不渲染的问题。
- 默认提示词强化为工具调用语义，提高高温度模型主动使用表情包的概率。
- 每次最大调用数量由玩家设置控制，默认 2 条，不采用不可修改的硬编码限制。
- 表情包控制提示词可在高级提示词设置中完整编辑。

## 九、智能生图系统

- 每个 AI 对话气泡新增“生图”入口，气泡决定向上扫描截止点和图片插入位置。
- 生图配置支持：
  - 玩家一句话核心画面描述
  - 1 至 10 轮历史扫描
  - 1:1、3:4、16:9 比例
  - 国风仙侠、二次元、真人、美漫与自定义画风
  - 安全模式
- 提示词组装 AI 会结合：
  - 玩家一句话最高优先级要求
  - 指定历史轮次
  - 当前角色卡人设
  - 角色绑定世界书命中内容
  - 比例与画风参数
- 提炼完成后提供中文正向、反向提示词预览，可手动编辑再提交。
- 安全模式会在不改变核心剧情和构图的前提下，将敏感表达改写为适合官方生图渠道的版本。
- 生图任务进入后台后可以继续聊天，并在顶部显示任务状态、等待时间和重试阶段。
- 失败任务可关闭、编辑提示词并重新生成。
- 重新生成时会读取最新绑定的生图渠道，不再锁死旧渠道。
- 生成图片插入对话时间线，支持删除、导出与重新生成。
- 支持独立生图渠道，不再要求绑定普通文字主渠道。
- 当前支持：
  - OpenAI 兼容 `/v1/images/generations`
  - NovelAI 官方图像协议
  - Nano Banana / Gemini 原生图像协议
  - ComfyUI API 工作流
- ComfyUI 支持导入 API 格式工作流，并通过手动或 AI 生成映射草案。
- 映射界面支持按节点下拉选择正向提示词、反向提示词、种子、宽度、高度和输出节点。
- 工作流与映射组合为通讯适配层，正式生图时只进行字段替换，不额外消耗 AI。
- 生图设置页提供测试图片功能，可在进入正式对话前验证渠道。
- 生图请求加强长耗时等待、退避重试、后台状态与超时说明，减少服务端成功但前端提前判定失败的问题。

## 十、模型渠道与密钥管理

- 文字模型渠道新增“获取模型”，调用 OpenAI 兼容 `/models` 接口并生成模型下拉列表。
- 保留手动填写模型名，兼容不提供模型列表接口的服务商。
- 新增模型渠道一键复制，可复制地址、密钥引用和参数，并自动命名为副本。
- 生图提示词模型采用与蒸馏模型一致的勾选式绑定方式。
- API Key 可直接输入，也可从密钥管理器选择已有命名密钥。
- 修复新密钥系统中模型仍读取旧 Key、造成 401 的优先级问题。
- 采样参数、最大上下文、思考模式和流式输出均可按模型或对话控制。

## 十一、同步中心与密钥保险库

- 新增独立同步中心，支持：
  - 本地 JSON 导入与导出
  - Microsoft OneDrive OAuth 2.0 PKCE
  - GitHub Secret Gist
  - Dropbox OAuth 2.0 PKCE
  - 私人 NAS WebDAV
- 同步为玩家手动触发的伪同步，不是实时自动同步。
- GitHub Gist 使用设备 ID 分离不同设备的同步文件，并选择最新有效数据。
- GitHub PAT 同时支持直接输入和从密钥管理器选择，并提供新手获取教程。
- 密钥管理器可保存命名 API Key、同步 Token、PAT、账号和密码。
- 模型、同步与生图渠道通过密钥 ID 引用本机密钥。
- 全局导出、导入和云同步均不会包含 API Key、OAuth Token、同步密码或调试快照。
- 导入业务数据不会覆盖本机密钥保险库。
- 手机端下载同步不再自动触发下载前安全备份，避免浏览器连续下载相同文件；改为明确提示玩家先手动备份。
- 桌面端下载同步仍会自动生成本地安全备份。
- 上传同步新增实时百分比、已上传大小、上传速度、预计剩余时间与取消按钮。
- 上传达到 100% 后仍会等待服务商返回最终确认，避免把“数据已发送”误判为“远端已保存”。
- OAuth 功能要求 HTTP(S) 页面；本地 `file://` 版本推荐使用 GitHub Gist 或本地 JSON。

- 设置页重组为：
  - 常用设置
  - 高级功能
  - 调试与使用须知
- 调试与使用须知仅保留调试功能和使用声明。
- 模型通道与设置之间新增独立“预设挡位（新手）”入口。
- 提供低耗、中耗、高耗三组配置，一键调整上下文、蒸馏、世界书和状态维护参数。
- 上下文轮数最低值调整为 1，保留完整调节空间。
- 删除无效的“延迟测试·暂无模型”区域，改为常见连接问题说明。
- 新增 400、401、403、404、429、5xx 与 CORS 常见错误解释。
- 高级提示词输入框直接显示完整实体默认提示词，不再要求玩家对照灰色 placeholder 修改。
- 功能性提示词均尽量开放编辑，包括蒸馏、状态书、缓存世界书、表情包、MVU、生图和 ComfyUI 映射。
- 设置页顶部加入 AI 内容与使用声明提醒。
- 全局将产品内置文本中的 `ai`、`Ai` 统一为正式写法 `AI`。
- 清理状态书页面中面向开发者的构建说明和无意义残留字段。

## 十三、调试、稳定性与界面改进

- 推理内容过滤兼容 `think`、`thinking`、`though`、`thought`、`reasoning`、`analysis`、`reflection`、`cot`、`scratchpad`、`planning` 等标签。
- 支持大小写、标签属性、方括号及未闭合标签过滤。
- 流式渲染使用帧合并，减少长回复频繁刷新造成的卡顿。
- 调试模式支持导出最终提示词、命中世界书、Token 估算和完整 API 原始响应。
- 输入框上方新增副 AI 状态条：
  - 发送前预告本条会触发状态书、缓存世界书或记忆蒸馏。
  - 执行时显示模型名与当前任务。
  - 玩家可直观看到副 AI 正在工作，而不是误认为页面卡死。
- API 请求加入低速率模式、429 退避与失败提示。
- 浅色和深色主题完成全局对比度审查，修复黑框灰字、弱边框与不可读说明文字。
- 统一紧凑面板标题、按钮尺寸、响应式布局和移动端弹窗层级。
- 顶部显示 `v1.39 早鸟测试`，并提示 v1.40 为最终稳定版。

## 十四、当前明确边界

- TTS 三层降级方案仅完成可行性报告，尚未落地。
- 云同步大缓存体积预检与渠道上限提示已完成设计审查，尚未正式实现。
- 云同步不进行分片、实时自动同步或服务端账号托管。
- GitHub 角色商店只访问公开仓库。
- ComfyUI 仅兼容 API 格式工作流，不负责节点安装、工作流教学或保证第三方工作流可用。
- MVU 不执行角色卡携带的 JavaScript、Tavern Helper 脚本或动态 Schema。
- 智能生图由玩家点击触发，不会自动根据每段正文批量生图。
- v1.39 仍属于早鸟测试版本，v1.40 将集中处理稳定性、兼容性与文档统一。
